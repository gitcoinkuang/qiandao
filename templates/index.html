总览
Automation Console

把签到任务、调度策略和异常反馈集中到同一个操作视图。

面向 Docker 部署的自动化控制台，支持任务管理、秒级调度、抢零点优化、通知推送与登录保护，适合长期托管和日常巡检。

部署方式 Docker / Compose
默认时区 Asia/Shanghai
通知通道 Telegram / Webhook
调度能力 支持时 / 分 / 秒

全局与单任务都能精确控制执行时间。

抢零点模式 更快触发与补发

适合 00:00 首签类任务，减少轮询带来的时间损耗。

访问保护 默认启用登录密码

避免裸露控制面板，兼顾远程部署场景。

控制台视图 总览看健康，任务做编辑，设置管策略
数据落盘 data/state.json 保存配置与历史
适用场景 社区签到、接口打卡、零点抢签
System Health

运行健康

根据最近执行结果快速判断成功率、失败比例与耗时表现。

Recent Runs

近期活动

关注最近触发的任务、执行状态和提示信息。

Timeline

最近记录

保留真实请求发起时间、状态码、耗时和响应片段，便于排查调度慢还是站点慢。

Task Center

任务列表

先在这里查看状态、筛选和巡检任务；需要创建或修改时，再进入独立编辑页，避免列表和表单同时拥挤。

Editor

创建任务

把 Curl 解析、请求配置、调度参数和预览结果拆到独立页面，让编辑时能专注在单个任务本身。

基础信息

定义任务名称、请求方法和目标地址。

Curl 解析与请求详情

可直接粘贴完整 Curl 命令，也可手动调整请求头与请求体。

执行策略

设置超时、重试和成功 / 失败关键词，用于判断结果与容错。

调度设置

支持单任务时分秒调度，也可以启用抢零点模式处理卡点任务。

预览结果 解析后在这里查看请求结构与当前任务详情。 
这里会显示解析结果或当前任务的详细信息。
Policy Center

全局策略与访问安全

统一管理默认调度时间、通知推送方式与控制台登录保护，适合长期部署后的维护场景。

Schedule

全局定时

为未启用单任务定时的任务提供默认执行时间与并发数量。

Notifications

通知设置

管理 Telegram 与 Webhook 推送策略，控制成功或失败时的告警行为。

Security

安全设置

建议始终启用登录保护，尤其在公网或家庭宽带场景中部署时。
