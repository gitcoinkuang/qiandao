# QianDao V2 - UI 重新设计方案

## 概述

对 QianDao V2（自动签到任务控制台）进行彻底的 UI 重新设计，从浅色蓝调风格改为深色极简卡片风，引入左侧固定侧边栏导航，保持原生 CSS + Vanilla JS 技术栈。

## 设计原则

- **功能优先**：每个视觉决策服务于可读性和操作效率
- **信息清晰**：高对比度、充足的间距、明确的视觉层级
- **耐看**：适合长期巡检和日常使用，不产生视觉疲劳
- **一致性**：统一的设计 tokens、组件样式、交互模式

## 布局结构

### 桌面 (>1024px)

- 左侧固定侧边栏 240px，始终可见
- 右侧主内容区，顶部为轻量顶栏（面包屑 + 快捷操作）
- 页面内容在顶栏下方滚动

### 平板 (768-1024px)

- 侧边栏折叠为图标栏 72px，文字隐藏，悬浮显示 tooltip

### 手机 (<768px)

- 侧边栏变为遮罩抽屉，通过汉堡图标打开/关闭

## 侧边栏

### 组成

```
Logo 区域：Q 图标 + "QianDao"
导航项：总览 / 任务 / 设置
分割线
底部状态：调度器运行状态 + 版本号
```

### 交互

- 当前页面：左侧 3px 青色竖条 + 文字加亮
- 悬浮态：背景微亮 `rgba(255,255,255,0.04)`
- 点击过渡：`background-color 0.15s ease`

## 页面设计

### 总览页

- **统计卡片行**：4 列网格，数字使用 Fira Code 大号显示，趋势微标（绿色 ↑ / 红色 ↓）
- **双栏内容**：左侧"运行健康"（进度条列表），右侧"近期活动"（紧凑事件列表）
- **最近记录**：Timeline 风格，等宽字体，状态码着色（2xx 绿/4xx 黄/5xx 红）

### 任务列表页

- **工具栏**：搜索框 + 筛选芯片组（全部/成功/失败/空闲）
- **任务卡片**：
  - 左侧 3px 状态色条（成功绿/失败红/空闲灰）
  - 名称粗体 + URL 灰色小字
  - 右上角状态徽标
  - 底部显示上次执行信息
  - 操作按钮 hover 展开
- **空状态**：居中提示 + 创建引导

### 任务编辑器页

- **分组卡片**：基础信息 / Curl 解析 / 执行策略 / 调度设置
- **表单控件**：`#1E293B` 背景输入框，青色聚焦边框
- **自定义开关**：青色填充
- **预览面板**：实时 JSON 预览
- **粘性底部**：保存/重置按钮组

### 设置页

- **2 列网格**：全局定时 + 通知设置 + 安全设置
- 复用编辑器的表单控件风格

### 登录页

- **双栏**：左侧品牌介绍区 + 右侧登录卡
- 与主站统一深色调

## 组件规范

### 按钮

| 类型 | 样式 |
|------|------|
| Primary | `#22D3EE` 背景，白色文字，悬浮微亮 |
| Secondary | `transparent` + `1px` 青色边框 |
| Ghost | `transparent` + `1px` 灰色边框 |
| Danger | `transparent` + `1px` 红色边框 + 红色文字 |

所有按钮：`border-radius: var(--radius-md)`，过渡 `0.15s ease`

### 卡片

- 背景 `#1A1F2E`，圆角 `var(--radius-xl)`
- 边框 `1px solid var(--line-strong)`
- 悬浮提升：`translateY(-1px)` + 阴影增强

### 表单输入

- 背景 `#1E293B`，边框 `var(--line-strong)`
- 聚焦：边框变 `#22D3EE`，`box-shadow: 0 0 0 3px rgba(34,211,238,0.12)`

### Toast 消息

- 右上角固定，暗色背景
- 成功：青色左边框
- 错误：红色左边框
- 动画：`slideIn 0.2s ease`

## 响应式断点

| 断点 | 行为 |
|------|------|
| >1024px | 桌面布局 |
| 768-1024px | 侧边栏折叠 |
| <768px | 抽屉侧边栏，卡片堆叠，全宽按钮 |

## 无障碍

- `prefers-reduced-motion` 尊重用户偏好
- 所有操作元素有 `focus-visible` 样式
- 表单输入关联 label
- 颜色对比度满足 WCAG AA 标准

## 技术约束

- 纯原生 CSS（使用 CSS 自定义属性）
- 纯 Vanilla JS（无框架）
- 后端 Go `html/template` 渲染
- SVG 图标（使用内联 SVG 或 Lucide 图标集）
- 无 emoji 作为 UI 图标
